# Install RustTalk on Windows

Works on Intel/AMD (x64) and ARM64 PCs. You don't need admin rights.

## Install

1. Download the installer from the
   [releases page](https://github.com/rusttalkcrew/rusttalk-next/releases/latest):
   `RustTalk-windows-x86_64.exe` for most PCs, `RustTalk-windows-aarch64.exe`
   for ARM PCs.
2. Double-click the file and follow the steps. RustTalk installs for your
   user only, so Windows won't ask for an administrator password.
3. Start RustTalk from the Start menu.

## If Windows says "Windows protected your PC"

The installer isn't signed with a paid Windows certificate yet, so SmartScreen
may warn about it. If you downloaded it from the link above:

1. Click **More info**.
2. Click **Run anyway**.

Not sure where the file came from? Close the window and
[check your download](verify.md) first.

## Updates

RustTalk checks for new versions by itself. When one is ready, a bar at the
top says "RustTalk vX.Y.Z is ready". Click **Update and restart**. RustTalk
installs the new version and opens again. To check by hand, use
**Settings → Updates → Check now**.

## Uninstall

Open **Settings → Apps → Installed apps**, find **RustTalk** and choose
**Uninstall**.

Uninstalling removes the app, not your settings or your keys. To remove those
too, open RustTalk first and use **Sign out of this device**. Do this only if
you still have your recovery words.
