# Directory rules

> **Draft.** These rules are a proposal and still need the maintainer's
> approval before they apply to the official directory (`index.rusttalk.com`).

The RustTalk directory helps people find public servers. Listing is free and
optional. To keep the directory a place people can trust, every listed server
must follow these rules. They cover what the directory shows (the server's
name, description and address) and what the server is plainly used for.
RustTalk servers are end-to-end encrypted, so the directory cannot see what
is said inside them; it acts on reports and on what it can see itself.

## A listed server must not

1. **Be illegal.** No child sexual abuse material, no selling of drugs,
   weapons or stolen data, and nothing else that is illegal where the
   directory is run.
2. **Scam people.** No phishing, fake giveaways, investment schemes or
   anything else that tricks people out of money, accounts or passwords.
3. **Spread hate or harass.** No servers built around attacking people for
   who they are, and no organised harassment, threats or doxxing.
4. **Promote violence or self-harm.** No terrorism, calls to violence, or
   encouraging people to hurt themselves.
5. **Mislead.** The name and description must honestly describe the server.
   Don't pretend to be another community, a company or RustTalk itself.
6. **Spam.** One listing per community. No keyword stuffing, ads for
   unrelated things, or listings that exist only to advertise.
7. **Show adult content in the listing.** Servers for adults may be listed,
   but their name and description must be safe for anyone to read and must
   say the server is for adults (18+).

## What happens when a server breaks the rules

Anyone can report a listed server with the **Report** button in
"Find servers". The directory's operator reviews reports and can:

- **Delist** the server: it disappears from the directory and can't list
  itself again under the same server ID.
- **Block** the server: as delist, and no server at the same address can be
  listed either.

The server's owner sees that it was removed, and why, on the server's
**Public listing** page. Removal from the directory does not affect the
server itself: its members can keep using it.

## Appeals

If you think your server was removed by mistake, or you've fixed the
problem, contact the directory's operator at the address shown on the
Public listing page. The operator can restore the server, and it shows up
again with its next refresh.

Other directories are run by other people and may have their own rules.
